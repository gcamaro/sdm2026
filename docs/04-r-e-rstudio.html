O primeiro dia no R e no RStudio

Organizar o trabalho reduz erros antes mesmo de escolher um algoritmo.

Base no curso: slides 105–118; 251–254.

No caderno da equipe

Uma pesquisadora executa uma linha no Console e obtém um objeto. O colega tenta repetir e recebe “objeto não encontrado”. Eles percebem que o histórico de cliques não pode ser o método. A equipe começa a trabalhar em um projeto e guarda os comandos em um script.

Linguagem, ambiente e projeto

O R executa comandos e fornece funções para ler dados, fazer análises e gerar saídas. O RStudio é uma interface de trabalho para o R. No editor ficam os scripts; no Console aparecem comandos e mensagens; o ambiente mostra objetos; as abas de arquivos, gráficos e ajuda apoiam a navegação. Salvar o script preserva os comandos, mas não garante que os arquivos de entrada estejam disponíveis.

Crie um projeto na pasta de modelagem do curso, onde estão a pasta Data e as pastas das espécies. Os scripts usam here::here() para formar caminhos a partir da raiz do projeto. Executar a cópia dentro da pasta deste livro, sem preparar essa estrutura, não reproduz o estudo.

Os primeiros comandos

R · exemplo didático adicional
# Um objeto recebe um valor com <-
especie <- "Zaprionus tuberculatus"
n_registros <- c(12, 8, 15)
sum(n_registros)
mean(n_registros)

# Uma função recebe argumentos entre parênteses
dados <- data.frame(fonte = c("campo", "coleção", "repositório"),
                    registros = n_registros)
str(dados)
?data.frame

Exemplo sintético e independente, sem registros reais da espécie. Use Ctrl+Enter (Windows/Linux) ou Cmd+Enter (macOS) no editor para executar a linha ou seleção.

Uma função combina uma operação com argumentos. pacote::funcao() indica de qual pacote vem a função. Um comentário começa com #; uma linha comentada não é executada. O operador %>%, usado nos scripts, passa um resultado para a próxima operação. Nomes de objetos diferenciam letras maiúsculas e minúsculas.

Instalar, carregar e registrar

Instalar um pacote o disponibiliza no computador; carregá-lo o torna acessível na sessão. Os scripts usam pacman para gerenciar pacotes, inclusive dependências do GitHub. Esse bloco requer conexão e pode instalar ou atualizar componentes. Registre versões e guarde o ambiente utilizado quando preparar uma análise para publicação.

R · trecho original · linhas 46–59
# Reprodutibilidade: antes de qualquer particionamento ou amostragem.
set.seed(1968)

# Carrega Pacotes -----------------------------------------------------------------------
# Instala Package Management Toll (pacman)
if (!require("pacman")) install.packages("pacman")

# Carrega os pacotes básicos necessários
# CRAN
pacman::p_load(
  ggplot2, sf, tmap, CoordinateCleaner, geodata, dplyr, rnaturalearth,
  corrplot, RColorBrewer, terra, scales, geobr, countrycode, gt, formattable,
  flextable, bdc, rgbif, openxlsx2, fuzzySim, sp, here, classInt, ragg, pROC
)

Se algo falhar

  • Leia a primeira mensagem de erro; as seguintes podem ser consequência dela.
  • Confira o caminho e a existência do arquivo, depois a estrutura do objeto com str().
  • Reinicie uma sessão limpa e siga a ordem do script para descobrir uma dependência oculta.
