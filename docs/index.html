O campo, o código e as decisões

O estudo de caso acompanha Zaprionus tuberculatus. A leitura simula o trabalho da equipe com o script do curso: preparar o projeto, conferir entradas, executar os blocos e interpretar as saídas. A base conceitual foi atualizada com os slides de 6 de novembro de 2026.

As situações de campo são didáticas. Os trechos de código indicam sua origem e os objetos necessários; comandos compactados e conferências adicionais estão identificados. Execute o script completo na ordem. Os valores do estudo devem ser preenchidos com as saídas da sua execução.
